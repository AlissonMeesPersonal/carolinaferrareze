# Imagem única da Comunidade BMC (sem carrossel)

A seção da comunidade exibe **apenas uma imagem estática**, como solicitado.
O componente é `components/CommunitySingleImage.jsx`, renderizado após o bloco
`#comunidade` e antes do conteúdo editorial.

## Arquivo exato

Suba a imagem enviada, **sem editar, recomprimir nem redimensionar**, para:

```
public/images/comunidade-bmc/aulas-preview.png
```

O arquivo deve ser PNG, resolução original **1774 × 887 px**.
O código já aponta para esse caminho.

1. Abrir `public/images/comunidade-bmc/` no GitHub.
2. Selecionar **Add file → Upload files**.
3. Enviar a foto original com o nome `aulas-preview.png`.
4. Confirmar o commit na branch `main`. A Vercel publicará automaticamente.

Não há reprodução de vídeo, rotação de slides, setas, bolinhas ou controles.
Em telas menores a imagem é reduzida proporcionalmente, **sem cortar**.
Se a imagem ainda não estiver no repositório, o bloco fica oculto para
não exibir uma imagem quebrada ao visitante.
