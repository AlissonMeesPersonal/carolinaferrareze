# Depoimentos — Carolina Ferrareze

Os arquivos SVG neste diretório apresentam **trechos de mensagens reais**, transcritos das capturas de tela exibidas na página 7 do PDF `Acompanhamento Terapêutico` fornecido pela cliente.

Eles **não são prints originais do WhatsApp**. São cartões gráficos que preservam o conteúdo essencial e omitem nomes, contatos e outras informações pessoais.

Caso a cliente prefira as capturas de tela originais, envie as versões autorizadas, com nomes e telefones ocultos, para esta pasta em JPG ou WebP e solicite substituição da galeria. Confira a autorização das pessoas antes de divulgá-las publicamente.
